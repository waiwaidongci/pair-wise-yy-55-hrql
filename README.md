# 音乐总谱编辑、移调与分谱出版准备平台

源提示词编号：12。支持多声部总谱、VexFlow 五线谱、音符与力度/连音/表情编辑、移调乐器、分谱提取与换页提示音、版本差异、评论锚点、撤销重做、打印和未保存恢复。

## 可离线的出版合并流程

针对「出版组与指挥同时改《潮汐线》、晚提交覆盖早提交、断网只剩最后一次自动保存」的问题，已补一条完整离线合并链路：

- **草稿隔离**：指挥 / 作曲 / 出版各有一份待合并草稿（各自的总谱、评论快照 + 基线 + 操作流水）。编辑不再直接写共享总谱，改动只进本人草稿，断网也可用。
- **锚点级三方比较**：合并队列按「声部 / 音符 / 评论锚点 × 字段」归组，并列展示来源、原值→新值与来源时间。多方新值不同即为**冲突**，锚点实体缺失为**阻塞**，必须由出版编辑显式选边或拒绝，系统不以「最后保存者」为准、绝不静默覆盖。
- **逐项合并**：网络恢复后由出版编辑逐项接受 / 拒绝，只有「出版编辑在线」身份能提交（`applyMerges` 带状态守卫）。冲突项必须所有来源都决定后才落入总谱。
- **rebase 不吞改动**：合并后其他草稿自动推进到新总谱；若某草稿对同一锚点有尚未合并的独立改动，保留其草稿值并生成「已合并结果 vs 草稿保留值」一对显式伪冲突，进入下一轮队列。
- **基线失效重算**：总谱一经合并，旧出版基线立即按锚点指纹重算并标记失效，列出全部偏离锚点；同小节、随旧基线解决的评论结论立即置为「待复核」，出版复核通过后方可重锁新基线。
- **分谱影响可见**：分谱页顶部按声部显示「冲突 N / 待合并 N / 已同步」与最新来源时间，分谱内冲突音符红框标注、未合并音符黄底，并列出每个锚点的来源与值；失效基线期间禁止付印提示。
- **可靠离线存储**：每次编辑原子写入三代轮转完整检查点（写新槽成功后才切换指针，不会只剩半截），指针内保存各检查点的操作流水摘要。最新检查点损坏时回滚到最近完整草稿，并逐笔列出晚于恢复点的丢失操作范围；三份尽毁时退回内置排练稿。
- **旧稿升级**：检测到 v1 单键草稿 `yy55-score-draft` 时，保留全部原音符与原评论，整体作为一个「旧稿升级」待合并草稿进入队列，按锚点逐项合并，不覆盖当前总谱。

核心实现：`src/merge/engine.ts`（diff / 三方比较 / rebase / 基线重算，纯函数）、`src/merge/storage.ts`（检查点与恢复）、`src/store.ts`（隔离编辑与合并动作）、`src/pages/MergeConsole.tsx`（离线合并台）。

```bash
npm run verify:merge   # 44 项端到端断言：冲突、逐项合并、rebase、基线失效、损坏恢复、旧稿升级
```
